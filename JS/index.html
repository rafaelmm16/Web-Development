1. Account Transactions (POO)

Implementação de uma classe Account com operações bancárias de depósito (crédito), saque (débito com verificação de saldo) e consulta de saldo. 

class Account {
  constructor(balance) {
    this.balance = balance;
  }

  debit(amount) {
    if (amount > this.balance) {
      return false;
    } else {
      this.balance -= amount;
      return true;
    }
  }

  getBalance() {
    return this.balance;
  }

  credit(amount) {
    this.balance += amount;
  }
}

2. Joined Logger (Higher-Order Function)

Função de alta ordem (closure) que filtra mensagens com nível de severidade maior ou igual ao mínimo definido e as une usando um separador customizado. 

function joinedLogger(level, sep) {
  return function (...messages) {
    const filteredMessages = messages.filter((msg) => msg.level >= level);
    const joinedText = filteredMessages.map((msg) => msg.text).join(sep);
    return joinedText;
  };
}
